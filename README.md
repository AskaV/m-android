📱 Android App (Jetpack Compose) — Modern UI Pages Demo

This is a small learning project built to practice creating screens using Jetpack Compose and modern Android development tools.
The project demonstrates multi-page navigation, custom UI components, and a clean architecture approach.


🚀 Main Features

Fully built with Jetpack Compose.
Multiple screens: Profile, Contacts, tabs, pager screens.
Navigation Compose for single-activity multi-screen navigation.
Reusable custom UI components (buttons, snackbars, tab layout, lists).
ViewModel-based state management (MVVM).
Material 3 theme support (light/dark/custom).
Image loading with Coil.
Loading states, resources usage, and clean UI structure.


🧩 Technologies & Libraries
🖌 UI / Compose

Jetpack Compose
Material 3
Navigation Compose
TabRow & Swipe navigation
Coil Compose (image loading)

⚙ Architecture

Kotlin MVVM
Optional DI support with Hilt

🎯 Purpose of the Project

Practice modern Android development with Jetpack Compose.
Learn how to build screens, navigation, and UI components without XML.
Understand MVVM and clean code structure.
Prepare for Android developer interviews.
